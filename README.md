Cash Quest

Cash Quest is a smart expense tracking and budgeting application designed to help users manage their finances effectively while 
Introducing gamification elements to encourage consistent and responsible spending habits.

Features
Authentication
Users can register and log in securely using a username and password.

Expense Categories
Users can create and manage custom expense categories such as:
Groceries
Entertainment
Transport

Expense Tracking
Add new expenses with:
Amount
Date
Description
Category
Option to attach a receipt photo for each expense.

Budget Management
Set a monthly budget goal
Define spending limits per category

Expense Overview
View a list of all expenses within a selected time period
Access uploaded receipt images directly from the expense list
View total spending per category

Data Visualization
Graph displaying daily spending over a selected period
Helps identify trends and spending patterns

Progress Dashboard
Displays how well users are staying within their budget
Highlights overspending categories visually

Gamification
Earn rewards or badges for:
Staying within budget
Consistent expense tracking

Data Storage
Initial version: Local database storage
Final version: Online database for multi-device access

Project Concept

Cash Quest combines financial management with gamification to make budgeting more engaging. 
The app not only tracks expenses but also motivates users to build better financial habits through rewards and visual feedback.

Technologies Used
Frontend: Android (Kotlin / XML) OR Web (HTML, CSS, JavaScript)
Backend: .NET / Firebase / Node.js
Database: Local DB (SQLite) → Online DB (Final version)
Tools: Android Studio / Visual Studio / GitHub

How the App Works
1) User creates an account or logs in
2) User creates expense categories
3) User logs daily expenses with optional receipts
4) User sets budget goals and category limits
5) App tracks and displays spending data
6) Dashboard shows progress and highlights overspending
7) User earns rewards for good financial behavior'
